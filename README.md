# 🎙️ AI Virtual Assistant  
An AI-powered virtual assistant that greets users, responds to voice commands, plays music, tells jokes, and performs Google searches.

## 🌟 Features  
- 🎤 **Voice Activation**: Click the mic button to speak commands.  
- 🎙️ **Greeting System**: Responds with a friendly greeting.  
- 🎵 **Play Music**: Plays a song on command.  
- 🤣 **Tell Jokes**: Provides random jokes.  
- 🔍 **Google Search**: Opens Google with your query.  

## 🚀 How It Works  
1. **Click the microphone button** to start speaking.  
2. **Say a command** like:  
   - 🗣️ `"Hello"` → *Assistant greets you back.*  
   - 🎶 `"Play music"` → *Starts playing music.*  
   - 🤣 `"Tell me a joke"` → *Assistant tells a joke.*  
   - 🔍 `"Search for cats on Google"` → *Opens Google search.*  

## 🛠️ Technologies Used  
- **HTML, CSS, JavaScript**  
- **Web Speech API** (Speech Recognition & Speech Synthesis)  

## 📜 Example Commands  
| Command | Response / Action |
|---------|------------------|
| `Hello` | "Hello! How can I assist you?" |
| `Play music` | Plays a song 🎵 |
| `Tell me a joke` | Tells a random joke 🤣 |
| `Search for cars on Google` | Opens Google search for "cars" 🔍 |
